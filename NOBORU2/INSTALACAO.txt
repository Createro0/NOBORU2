INSTRUCOES DE INSTALACAO - NOBORU2 TEST VPK
============================================

REQUISITOS:
- PS Vita com VitaShell ou similar
- Arquivo: NOBORU2-test.vpk

PASSO A PASSO:

1. TRANSFERIR ARQUIVO:
   - Conectar PS Vita ao PC
   - Copiar NOBORU2-test.vpk para ux0:/PSP2/UPDATE/ ou pendrive
   - Se via pendrive, copiar tambem para ps vita

2. INSTALAR NO VITA:
   - Abrir VitaShell
   - Navegar para onde esta o .vpk
   - Pressionar X no arquivo NOBORU2-test.vpk
   - Selecionar "Install"
   - Aguardar conclusao (pode levar minutos)

3. CONFIGURAR APLICACAO:
   - Home > Library > NOBORU 2 (ou similar)
   - Executar aplicacao
   - Aguardar carregamento (vai demorar na primeira vez)
   - Ir para Settings (triangulo)
   - Procurar "NSFW" > Mudar para ON
   - Voltar para menu principal

4. ACESSAR NHENTAI:
   - Clicar em "Catalog" ou "Navegador"
   - Deve ver "nhentai" na lista de parsers
   - Se nao ver, reiniciar app e tentar novamente

TROUBLESHOOTING:

Se nhentai nao aparecer:
   - Limpar cache: Settings > Clear Cache
   - Reiniciar aplicacao
   - Verificar se NSFW esta ligado

Se tiver erro de instalacao:
   - Verificar se tem 1.5GB livre no ux0:/
   - Tentar instalar de pendrive em vez de PC
   - Reinstalar arquivo .vpk

Se imagens nao carregam:
   - Problema conhecido com .webp
   - Tentar desabilitar animacoes em Settings
   - Reiniciar app e tentar novamente

NOTAS IMPORTANTES:
- Primeira execucao pode demorar muito
- Conexao de internet necessaria para buscar mangás
- WiFi mais estavel do que USB

SUPORTE:
Verificar https://github.com/Createro0/NOBORU2 para atualizacoes
